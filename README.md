# Personal Vehicle Maintenance Log

A console-based Python application to manage vehicle details,
maintenance records, service expenses, and upcoming maintenance.

## Features

- Register vehicles
- View registered vehicles
- Add maintenance records
- Track odometer readings
- Record maintenance expenses
- Track next due dates
- Search maintenance history
- View upcoming maintenance
- View overdue maintenance
- Generate expense reports
- Store data using JSON

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Lists and Dictionaries
- DateTime

## Installation


Navigate to the project directory:

```bash
cd Personal_Vehicle_Maintenance_Log
```

Run the application:

```bash
python main.py
```

## Example Maintenance Records

- Regular Servicing
- Oil Change
- Tyre Replacement
- Insurance Renewal
- Battery Replacement
- Vehicle Repair

## Data Storage

Vehicle information is stored in:

`data/vehicles.json`

Maintenance records are stored in:

`data/maintenance.json`
